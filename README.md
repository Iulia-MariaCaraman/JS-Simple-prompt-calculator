# Simple Prompt Calculator

A beginner-friendly calculator built with Vanilla JavaScript and HTML, based on exercises from the Cisco Networking Academy - JavaScript Essentials 1 course.

## Overview
The application takes two numbers and an arithmetic operator from the user sequentially using the browser's `prompt()` function, performs the calculation, and displays the result via `alert()`.

## Features
- Handles basic operations: addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- Performs explicit string-to-number type conversion.
- Validates user input using `Number.isNaN()`.
- Implements error handling for invalid operations and division by zero.

## Technologies Used
- JavaScript (ES6)
- HTML5

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. Click the button to start the calculator.
